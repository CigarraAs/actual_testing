Roleas y Carga Horaria (Regla 50/50)

Para mitigar retrasos en el desarrollo y maximizar la entrega de código de pruebas, se utiliza un modelo de co-responsabilidad técnica. Los líderes de sprint actúan además como desarrolladores y los no-desarrolladores asumen programación de apoyo:

💻 Programadores de Pruebas

  • • Dedicación ordinaria: 100% Desarrollo de Tests (Dev).
  • • Rol en caso de Liderazgo: 50% Gestión / 50% Dev.
  • • Foco: Codificación pura, mockeo y testing de suites core (Vitest/Playwright).

📂 Roles Especialistas (Doc/QA, Reviewer)

  • • Dedicación ordinaria: 50% Especialidad / 50% Dev.
  • • Rol en caso de Liderazgo: 50% Gestión / 50% Especialidad.
  • • Foco: Wiki, Pages y alineamiento, junto con codificación auxiliar.
